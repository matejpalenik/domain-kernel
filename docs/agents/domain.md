# Domain docs

Domain Kernel uses a single context. Before exploring domain behavior, read
the root `GLOSSARY.md` and relevant decisions in `docs/adr/`, if present.
Use the glossary's terms and flag conflicts with existing ADRs. Continue
without placeholders when these docs do not yet exist.
[Grill with Docs](../../.agents/skills/grill-with-docs/SKILL.md) records terms
and decisions during a design interview.
