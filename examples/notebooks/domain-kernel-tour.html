From AI Act evidence to a model you can ship¶

Build a model for the developer designing a recruitment application. They need to tell technical documentation from instructions for use, see which fields to store, and trace a definition back to the AI Act. You will hand them a reviewed model and a JSON Schema.

With Python 3.13 or newer, run this from the repository root:

uv sync --locked --group notebook --extra documents --extra inference --extra discovery-workflow

Put OPENAI_API_KEY in the Git-ignored root .env and select the project's .venv/bin/python kernel. Choose Restart Kernel after updating the environment, then Run All. The first live run downloads the publisher PDF and uses paid GPT-6 Luna calls to orient, draft and review. Run All again in the same workspace to reopen the saved result. The saved walkthrough outputs are simulated using a synthetic PDF and scripted provider replies. They are not a live run or a benchmark.

Discover concepts and relationships¶

Pass the source revision to discover(). Discovery uses the model description as its purpose. For a long packet it orients across the source, then retrieves passages and checks the draft against the purpose. Inspect the proposals and exact evidence before editing them.

For a closer look at citations and run failures, open Discover a recruitment model.

Review the model¶

For this release, the sample reviewer selects the meanings needed by a developer implementing instructions for use. The release also distinguishes technical documentation and records who supplies the instructions. Other suggestions remain visible in the discovery run and are marked outside this release.

async def review_case(
    *, model: Model, case: ReviewCase, decision: ReviewAction, actor: str
) -> None:
    """Preview a decision and record it once under the sample reviewer's name."""
    case = await model.get_review_case(case_id=case.id)
    name = case.definitions[0].name
    if case.status is CaseStatus.PENDING:
        impact = await model.preview_changes(case=case, decision=decision)
        print(f"Preview {name} · {len(impact.definition_changes)} definition changes")
        receipt = await model.decide_review(
            case=case,
            decision=decision,
            actor=actor,
            idempotency_key=f"review-{case.id.value}",
        )
        print(f"Reviewed {name} · {actor} · decision {receipt.decision_id.value}")
    else:
        print(f"Reopened review of {name} · {case.status.value}")
