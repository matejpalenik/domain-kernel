# Contributing and support

Start with the <RepositoryLink path="CONTRIBUTING.md">contributor guide</RepositoryLink>
for local setup, quality checks, and pull requests. To edit or preview this
site, follow the

<RepositoryLink path="docs/documentation.md">
  documentation development guide
</RepositoryLink>
. Merging a change does not publish the site.

## Get help and report security issues

Use [GitHub issues](https://github.com/matejpalenik/domain-kernel/issues) for bugs
and documentation questions. Include the source revision and a minimal example.

Report suspected vulnerabilities privately using the

<RepositoryLink path="SECURITY.md">security policy</RepositoryLink>.
