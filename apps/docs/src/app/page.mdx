# Give your application a shared language

Your application needs more than searchable documents. It needs to know what a
concept means, how it relates to other concepts, and which source or decision
supports that meaning.

Domain Kernel is an embeddable Python SDK that turns that knowledge into
a reviewed, versioned domain model. Your application can then use the model as a
shared contract for its interfaces, data structures and analysis.

<ModelJourney />

## Start with a concrete problem

You are building legislative-analysis software for an organisation whose clients
use AI in recruitment. The AI Act describes providers, deployers, intended
purposes, documentation and safeguards across many provisions. Your application
needs stable definitions that preserve these distinctions and remain connected
to their evidence.

## Keep application decisions in your application

Domain Kernel is intended to supply reusable meanings, evidence, constraints and
review history. An ERP builder, FDE workbench, Graph RAG platform or legislative
analysis tool decides how to use that contract. Operational records, user-facing
workflows and conclusions about particular cases belong to those applications.
