# From AI Act evidence to a model you can ship

You're building an application to help your team analyse AI in recruitment.
Start with Article 13 and decide how your application should distinguish
instructions for use from technical documentation. Then review the draft and

## Run the notebook

Clone the repository or extract the matching source download above. From its root,
with Python 3.13 or newer and uv 0.13.7 or newer, run:

<CodeGroup>

```sh
uv sync --locked --group notebook --extra documents --extra inference --extra discovery-workflow
```

</CodeGroup>

Open the repository folder in VS Code with the Python and Jupyter extensions.
Open `examples/notebooks/domain-kernel-tour.ipynb`, select `.venv/bin/python` as
the kernel, and choose **Run All**. Put `OPENAI_API_KEY` in the Git-ignored
repository-root `.env` before running. The notebook downloads the pinned English
AI Act PDF and stores the text Docling extracts in SQLite. Discovery uses
GPT-6 Luna to orient, draft and review. A restart reopens the same result
without another paid call. The saved walkthrough uses simulated inputs and replies.
